One line, under 200 characters, in which a dog explains why it ate the
homework — in the dog's own voice, after being caught. The dog followed
orders: sit, stay, do the homework. So it did. All of it.

`main.py` (stdlib only) copies the pre-written line in `entry.txt` to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, validating UTF-8, 1–200 characters,
non-whitespace, and a single line.
